As cores da marca

Estas são as únicas três cores da PC&MR. Use sempre os mesmos códigos para manter a consistência.

Azul-marinho#15294D
Cor principal · confiança
Coral#F14E49
Vermelho coral · destaque · energia
Marfim#FCF9ED
Fundo claro · premium

Tipografia: Montserrat (negrito para o logo e títulos). É uma fonte gratuita do Google Fonts e do Canva.

Suas versões do logo

Você tem 5 versões. Cada uma serve para uma situação. Nunca recrie o logo — use sempre os arquivos prontos.

🎨
1. Logo principal (colorido, fundo marfim)
Com "Corretora de Seguros". Para site, cartão de visita, fachada, documentos oficiais, materiais institucionais.
⭕
2. Avatar (PC&MR no quadrado marfim)
Foto de perfil: WhatsApp, Instagram, Facebook, Google. Já está no ar no seu WhatsApp.
✉️
3. Minimalista (só PC&MR, sem "corretora")
Assinatura de e-mail, cabeçalho de site, marca d'água, qualquer espaço pequeno ou horizontal.
🌙
4. Fundo escuro (logo branco em marinho)
Stories, banners escuros, posts com fundo colorido/foto. Quando o fundo é escuro, use SEMPRE esta versão.
📄
5. Preto e branco
Documentos impressos, contratos, carimbo, fax, qualquer impressão sem cor.

Pode fazer

Boas práticas que mantêm a marca forte.

✓
Trocar o fundo conforme a ocasião — datas comemorativas, campanhas. O fundo é flexível.
✓
Usar a versão certa para cada fundo — logo colorido em fundo claro, logo branco em fundo escuro.
✓
Dar espaço ao redor do logo — deixe um "respiro" em volta, não cole em outros elementos.
✓
Manter as proporções — ao redimensionar, segure a tecla Shift para não distorcer.

Não faça

O que enfraquece ou descaracteriza a marca.

✕
Não troque as cores — o azul é sempre #15294D, o coral sempre #F14E49. Nada de inventar tons.
✕
Não estique nem achate — distorcer o logo passa amadorismo.
✕
Não ponha logo colorido em fundo escuro — ele some. Use a versão branca.
✕
Não troque a fonte — é sempre Montserrat. Outra fonte vira outra marca.
