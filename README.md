# Novo site da PC&MR Corretora de Seguros

Projeto independente para desenvolvimento do novo site institucional da PC&MR Corretora de Seguros, criado do zero.

O site atual em https://www.pcmrcorretora.com.br/ serve apenas como referência de informações comerciais e institucionais, não de layout, estrutura ou código.

## Objetivo
Construir um site original, moderno, responsivo, acessível e orientado à solicitação de cotações. O desenvolvimento deve ocorrer exclusivamente neste repositório e não deve alterar o projeto FluxBroker nem o domínio em produção.

## Próximos passos
O Codex deverá criar a aplicação, organizar os arquivos, implementar a experiência e documentar como executá-la e testá-la.
